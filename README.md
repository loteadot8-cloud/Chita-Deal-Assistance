# Дмитрий · Недвижимость в Чите

Одностраничный сайт для собственников, которые хотят продать квартиру, дом, дачу, гараж или машиноместо в Чите и пригороде.

React, TypeScript, Vite, Tailwind CSS, Motion и lucide-react. Кириллические шрифты Onest, Golos Text и JetBrains Mono поставляются вместе со сборкой. Кнопки ведут на объявление и профиль Авито.

## Локальный запуск

Требуется Node.js 24.

```sh
npm ci
npm run dev
```

Проверка TypeScript и production-сборка выполняются командой `npm run build`. Готовые файлы находятся в `dist/`.

## GitHub Pages

Поместите файлы проекта в корень отдельного GitHub-репозитория с основной веткой `main`. В Settings → Pages → Build and deployment выберите GitHub Actions. Запустите workflow **Deploy to GitHub Pages** во вкладке Actions. После этого он будет автоматически публиковать изменения из `main`.

Цена указана в `src/App.tsx`, ссылки на Авито находятся в `src/content.ts`. Уведомление о дате начала выездов скрывается с 17 декабря 2026 года по времени Читы.

Первый экран, вкладки объектов и раскрывающиеся услуги вынесены в `src/components/`. Анимации учитывают настройку системы «Уменьшение движения».
